## 브랜드 컨셉 (원문 그대로)
- 서비스명: Paw:Paw (Paw + Paw = 강아지와 고양이 두 마리가 함께하는 돌봄)
- 슬로건: "우리 아이의 하루를, AI가 함께 돌봐요"
- 톤앤매너: 병원처럼 차갑지 않고 다정하고 따뜻한 돌봄의 느낌. 부드러운 3D 클레이/펠트 질감 캐릭터 일러스트 + 라운드 컴포넌트로 친근함 강조
- 로고 모티프: 발바닥(paw) 모양이 "P"자와 결합된 워드마크. 원형 그라데이션 링(민트→퍼플) 안에 심전도 파형(건강) + 막대그래프(데이터 트래킹) 아이콘

## v3 디자인 시스템 (2026-10, "Warm Clinical")
> 기능·마스코트(Lottie)·말풍선·로딩 발자국 애니메이션·Paw:Paw 워드마크는 그대로 두고, 전반적인 디자인과 아이콘만 개편했다.
> 방향: 병원처럼 차갑지 않되 데이터는 또렷하게 읽히는 에디토리얼 톤. 브랜드 색의 **의미 규칙은 v2와 동일**하다.

## 타이포그래피
- 폰트: **Pretendard Variable** (jsDelivr dynamic subset — 실제 쓰는 글자만 내려받음). 대체: Apple SD Gothic Neo → Noto Sans KR → Malgun Gothic.
- Pretendard는 공백 글리프가 좁아(0.24em) 한글 띄어쓰기가 붙어 보이므로 `body`에 `word-spacing: 0.06em` 보정. 본문에 음수 자간 금지(제목에만 `tracking-tight`).
- 위계: 페이지 제목 `text-2xl~4xl font-extrabold tracking-tight` → 카드 제목 `15px bold` → 본문 `text-sm` → 캡션 `text-xs text-muted`.
- 숫자 데이터(체중, 0/2, %)는 `tabular-nums`. **단, 하이픈이 들어간 날짜·D-day에는 쓰지 않는다**(Pretendard tnum이 하이픈 폭까지 고정폭으로 바꿔 간격이 벌어짐).

## 아이콘
- **lucide-react**로 통일 (`+`, `×`, `‹ ›`, `✓` 같은 텍스트 기호 금지). 기본 strokeWidth 2, 버튼 안 13~16px, 카드 칩 15px.
- 카드 헤더는 `Card`의 `icon`/`tone` prop으로 의미 색 아이콘 칩(`IconChip`)을 붙인다 — mint=복약·완료, amber=일정, purple=AI, neutral=일반.
- 주요 매핑: 복약 `Tablets`, 예방접종 `Syringe`, 체중 `Scale`, 캘린더 `CalendarDays`, 건강 기록 `HeartPulse`(AI 자동 기록이라 purple), AI `Sparkles`, 레포트 `FileText`.

## 레이아웃 & 컴포넌트 공통 규칙
- **NAV바**: 데스크톱은 중앙 세그먼트 내비게이션(활성 = 흰 칩 + 그림자) + 우측 알림·사용자·로그아웃. **모바일(<768px)은 하단 탭 바** — 본문 하단 여백(`pb-28`)과 토스트 위치(`bottom-24`)를 탭 바만큼 띄운다.
- **카드**: `rounded-3xl` + hairline 보더 + `shadow-card`. 카드 안 보조 수치 묶음은 `surface-muted` 트랙 + `divide-x`.
- **버튼**: 모두 pill. Primary = ink 배경 + 흰 글자, Secondary = 흰 배경 + 보더, Danger = coral-deep 글자 + 옅은 coral hover, 카드 헤더 보조 액션 = `CHIP_BUTTON_CLASS`. 공통 클래스는 `constants/formStyles.js`.
- **입력/토글**: 입력창은 흰 배경 + 포커스 시 민트 링. 선택지 토글은 세그먼트 컨트롤(트랙 + 선택된 흰 칩).
- **모달**: 배경 블러 + 등장 애니메이션, 닫기는 `X` 아이콘.
- **숫자 표기(n/m)**: 미완료 coral 계열, 완료 mint 계열 배지.
- **AI 챗봇**: AI 답변은 왼쪽 purple `Sparkles` 아바타 + 흰 말풍선, 사용자 메시지는 ink 말풍선. 자동 기록 안내는 purple-soft 박스.
- **접근성**: 키보드 포커스 시 민트 outline(`:focus-visible`), `prefers-reduced-motion` 시 애니메이션 최소화.
- **캐릭터 일러스트**: 마스코트/말풍선/로딩 Lottie는 아이덴티티 요소라 v3 개편 대상에서 제외.

## 메인페이지·건강 레포트·인트로 페이지 신규 디자인 시 참고할 것
레퍼런스가 없는 이 화면들은 아래를 그대로 지키면 다른 화면과 이질감이 없습니다.
- 메인페이지(간소화 대시보드): NAV바 규칙 동일 적용, D-Day 카드는 amber, 복약 캘린더는 완료=mint/미완료=coral. 중앙 마스코트 애니메이션 자리, 말풍선은 알림 우선순위 로직 반영 (`docs/features/dashboard.md` 참고)
- 건강 레포트: 체중 그래프는 `docs/SPEC.md`의 보간 규칙(미입력일은 전날 값 유지)이 시각적으로도 끊김 없이 보이게, AI 의심사항 텍스트에는 반드시 출처 표기 + purple 포인트로 "AI가 분석한 부분"임을 구분
- 인트로 페이지(로그인 전 첫 화면): 히어로 텍스트 + 3개 특징 카드 + 로그인 카드(카카오 버튼만) 구조. `docs/features/intro.md` 참고 — 레이아웃 구조는 참고 자료를 따르되 색상은 반드시 위 토큰(민트/퍼플/아이보리)만 사용, 다른 톤(예: 블루 계열)을 가져오지 않는다

## 성능/무게 가이드라인 (반드시 지킬 것)
1. 클레이/펠트 질감 캐릭터에 Lottie를 쓴다면 마스코트+로딩 인디케이터 두 곳에만, 지연 로드로
2. 폰트는 Pretendard Variable dynamic subset 1종만 로드 (가변 폰트라 웨이트별 파일이 따로 없음)
3. 마스코트 외 모션은 CSS transition으로, 별도 스크롤 애니메이션 라이브러리 도입하지 않기
4. 색상은 위 토큰만 사용 — 레퍼런스 코드처럼 `style={{ color: '#...' }}` 인라인 하드코딩 금지, 반드시 `tailwind.config`에 토큰으로 등록 (`client/CLAUDE.md` 규칙과 동일)

## 성능/무게 가이드라인 (반드시 지킬 것)
포트폴리오용이라도 로딩이 느리면 시연에서 감점 요인이 된다. 아래를 지킨다.

1. **Lottie는 마스코트 + 공용 로딩 인디케이터 두 곳에만.** 마스코트는 종(dog/cat)당 애니메이션 1개로 시작 — 상태별(평온/걱정/배고픔/기쁨) 세분화는 필요해지면 추가한다. 다른 UI 요소(버튼, 카드)에는 Lottie를 쓰지 않는다.
2. **Lottie 라이브러리와 JSON은 지연 로드.** `Mascot`/`LoadingPaws` 컴포넌트 내부에서 `React.lazy` + 동적 `import()`로 실제 마운트 시점에만 불러온다 — 정적 import 금지. 여러 페이지에서 같은 라이브러리 청크를 재사용하므로 세션 중 한 번만 받으면 된다.
3. 마스코트 외의 모션은 CSS transition(호버·탭 피드백 수준)으로 처리하고, 별도의 스크롤 애니메이션 라이브러리는 도입하지 않는다.
4. 그래프(체중 변화)는 가벼운 SVG 기반 라이브러리 하나만 선정해서 통일 사용 — 차트 라이브러리를 기능별로 다르게 쓰지 않는다.
5. 웹폰트는 위에 정한 2개 서체, 서체당 2~3 굵기로 제한하고 필요한 subset만 로드한다.
